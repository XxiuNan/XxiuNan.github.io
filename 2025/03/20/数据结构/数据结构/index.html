二. 算法

  1. 算法的重要特性

    1. 有穷性
    2. 确定性
    3. 可行性
    4. 输入
    5. 输出

  2. “好”算法的目标

    1. 正确性
    2. 可读性
    3. 健壮性
    4. 效率与低存储量需求

  3. 时间复杂度

    O(1) < O(log_2{n}) < O(n) < O(nlog_2{n}) < O(n²) < O(n³) < O(2^n) < O(n!) < O(n^n)

  4. 算法原地工作

    指算法所需辅助空间是常量

  5. 同一个算法, 实现的语言级别越高, 执行效率越低

  6. 相同规模n下, 复杂度为O(n)的算法在时间上总是优于复杂度为O(n²)的算法

  7. 所谓时间复杂度, 是指最坏情况下估算算法执行时间的一个上界

三. 树与二叉树

  1. 树是一种递归的数据结构, 是一种逻辑结构, 同时也是一种分层结构

  2. n个节点的树有n-1条边

  3. 树的基本性质

    1. 树中的节点数等于所有节点的度之和加1;
    2. 度为m的树中第i层上至多有m^(i - 1)个节点(i >= 1);
    3. 高度为h的m叉树至多有(m^n - 1) / (m - 1)个节点
    4. 具有n个节点的m叉树的最小高度为[log_m{n (m - 1) + 1}]

3.2 二叉树

  1. 满二叉树
>   2 ^ n - 1个节点
  1. 一棵有n个节点的二叉树采用二叉链表存储节点
>   1.   其中非空指针数 = 总分支数 = n - 1
>   2.   空指针数 = 2 * 节点总数 - 非空指针数 = n + 1
  1. 二叉树是有序树

3.3 二叉树的性质

  1. 非空二叉树上的叶子节点数等于度为2的节点数加1

    n0 = n2 + 1

  2. 非空二叉树第k层上至多有2 ^ (k - 1)个节点(k >= 1)

  3. 高度为h的二叉树至多有2 ^ h - 1个节点(h >= 1)

  4. 在含有n个节点的二叉树中, 有n + 1个空指针

  5. 对完全二叉树按从上到下, 从左到右的顺序依次编号1, 2, …, n, 则有以下关系

    1. 当i > 1时, 节点i的双亲的编号为$\left \lfloor i / 2 \right \rfloor $, 即当i为偶数时, 其双亲编号为i / 2, 它是双亲的左孩子; 当 i 为奇数时, 其双亲的编号为 (i - 1) / 2, 它是双亲的右孩子
    2. 当2i <= n时, 节点 i 的左孩子编号为2i, 否则无左孩子
    3. 当2i + 1 <= n时, 节点 i 的右孩子编号为2i + 1, 否则无右孩子
    4. 节点 i 所在层次(深度)为$\left \lfloor log_2{i}\right \rfloor + 1$

  6. 具有n(n > 0) 个节点的完全二叉树的高度为$\left \lceil \log_2{(n + 1)} \right \rceil $或$\left \lfloor log_2{n} \right \rfloor + 1$

    设高度为h, 根据性质3和完全二叉树的定义有 $2 ^ {h - 1} - 1 < n <= 2 ^ h - 1 $或 $2 ^ {h - 1} <= n < 2 ^ h$

    得$2^{h - 1} < n + 1 <= 2 ^ h$, 即$ h - 1 < log_2{n + 1} <= h$, 因为h为正整数, 所以$h = \left \lceil log_2{n + 1} \right \rceil $.

    或得 $h - 1 <= log_2{n} < h$, 所以 h = $\log_2{n} + 1$;

3.4 线索二叉树

  1. 由二叉树的先序序列和中序序列可以唯一的确定一棵二叉树

  2. 二叉树的线索化, 即遍历一次二叉树

  3. 在三序遍历中, 叶子节点的先后顺序是完全相同的

  4. 先序和后序不能唯一确定一棵二叉树

  5. 线索二叉树是一种物理结构

  6. 二叉树线索化不能解决后续线索二叉树中求后序后继的问题

  7. 后序线索二叉树的遍历需要栈的支持

  8. 对于n个不同元素进栈, 出栈序列的个数为卡特兰数 $$\frac{1}{n+1} C_{2n}^{n}$$

  9. 一个二叉树, 前序序列和后序序列正好相反, 则 h = n

  10. a, b为一个二叉树中的两个节点

    1. 前序序列中a在b之前, 中序序列中a在b之后, 则节点b在节点a的左子树
    2. 前序序列中a在b之前, 后序序列中a在b之后, 则节点a是节点b的祖先

  11. 后序遍历时, n在m前的条件是: n是m的子孙

  12. 中序遍历时, n在m前的条件是: n在m左方

  13. m是n的祖先, 则使用后序遍历可以找到m到n的路径

3.5 树的表示方法

  1. 树的存储结构

    1. 双亲表示法

      伪指针域存储父节点数组下标

    2. 孩子表示法

      每个节点的孩子节点单独存放为一条链表

    3. 孩子兄弟表示法(二叉树表示法)

      以二叉链表作为树的存储结构

  2. 将森林F转换为对应的二叉树T, 则F中叶节点的个数等于T中左孩子指针为空的节点个数

3.6 树与二叉树的应用

  1. 哈夫曼树

    1. 带权路径长度$WPL = \sum_{i = 1}^{n} w_{i}l_{i} $

    2. 每个初始节点都成为叶节点, 且权值越小的节点到根节点的路径长度越大

    3. 构造过程中总共创建了n - 1个双分支节点, 哈夫曼树节点总数: 2n - 1

    4. 哈夫曼树不存在度为1的节点

    5. 在有n个叶子节点的哈夫曼树中, 非叶子节点个数为n - 1

      哈夫曼树中只有度为0和度为2的节点, $n_0 = n_2 + 1$ => $n_2 = n - 1$

  2. 前缀编码

    若没有一个编码是另一个编码的前缀, 则称这样的编码为前缀编码

  3. 并查集

    并查集是用双亲表示法存储的树, 为了方便集合的合并和查找根节点

    令union操作实现小树合并到大树功能后, 构造的树高度不会超过$\left \lfloor \log_{2}{n} \right \rfloor +1$

  4. 邻接矩阵

  5. 十字链表法

    只能用来存储有向图

  6. 邻接多重表

    只能用于存储无向图

五. 查找

一. 概念

  1. 静态查找表: 只涉及数据的查找

    1. 查询某个特定的数据元素是否在查找表中
    2. 检索满足条件的某个特定的数据元素的各种属性
    3. 顺序查找, 折半查找, 散列查找

  2. 动态查找表: 需要动态的插入或删除一些数据的查找表

    1. 在查找表中插入一个数据元素
    2. 从查找表中删除某个数据元素
    3. 二叉排序树的查找, 散列查找

​ 注: 二叉平衡树和B树都是二叉排序树的改进

  1. 关键字: 数据元素中唯一标识该元素的某个数据项的值

  2. 平均查找长度: 所有查找过程中进行关键字的比较次数的平均值
    $$
    ASL = \sum_{i = 1}^{n} P_iC_i
    $$

    式中, n是查找表的长度; $P_i$是查找第i个数据元素的概率, 一般认为每个数据元素的查找概率相等, 即$P_i = 1 / n$;

    $C_i$是找到第i个元素所需进行的比较次数. 平均查找长度是衡量查找算法效率的最主要的指标.

二. 顺序查找和折半查找

  1. 一般线性表的顺序查找

$$
ASL_{成功} = \sum_{i = 1}^{n} P_i(n - i + 1) = \frac{n + 1}{2}
$$

$$
ASL_{失败} = n + 1
$$

  1. 有序表的顺序查找

$$
ASL_{成功} = \frac{n + 1}{2}
$$

$$
ASL_{失败} = \sum_{j = 1}^{n} q_j(l_j - 1) = \frac{1 + 2 + … + n + n}{n + 1} = \frac{n}{2} + \frac{n}{n + 1}
$$

$q_j$是到达第j个失败节点的概率, 在相等查找概率的情形下, 它是$\frac{1}{n + 1}$;

$l_j$是第j个失败节点所在的层数

  1. 折半查找, 又称二分查找, 仅适用于有序的顺序表

$$
ASL_{成功} = \frac{1}{n}\sum_{i = 1}^{n}l_i = \frac{1}{n}(11+22+…+h*2^{h -1}) = \frac{n + 1}{n}log_{2}{(n + 1)} - 1 \approx log_{2}{(n + 1)} - 1
$$

$$
ASL_{失败} = \frac{1}{n + 1}\sum_{i = 1}^{n}l_i = \frac{1}{n + 1}(3 * 4 + 4 * 8 +…+ h * 2^{h - 1})
$$

  1. 分块查找, 又称索引顺序查找: 吸取了顺序查找和折半查找的有点, 既有动态结构, 又适合快速查找

    设索引查找和块内查找的平均查找长度分别位$L_I, L_S$, 则分块查找的平均查找长度为$ASL = L_I + L_S$

    将长度为n的查找表均匀地分为b块, 每块有s个记录, 在等概率情况下, 若在块内和索引表中均采用顺序查找, 则平均查找长度为

$$
ASL = L_I + L_S = \frac{b + 1}{2} + \frac{s + 1}{2} = \frac{s^2 + 2s + n}{2s}
$$

​ 此时, 若$s = \sqrt{n}$, 则平均查找长度取最小值$\sqrt{n} + 1$; 若对索引表采用折半查找时, 则平均查找长度为
$$
ASL = L_I + L_S = \left \lceil log_2{(b + 1)} \right \rceil + \frac{s + 1}{2}
$$

二. 红黑树

  1. 定义

    1. 每个节点或是黑色, 或是红色
    2. 根节点是黑色的
    3. 叶节点(虚构的外部节点, null节点)都是黑色的
    4. 不存在两个相邻的红节点(即红节点的父节点和孩子节点均是黑色的)
    5. 对每个节点, 从该节点到任意叶节点的简单路径上, 所含黑节点的数量相同

  2. 从某节点出发(不含该节点)到达一个叶节点的任意简单路径上的黑节点总数称为该节点的黑高, 记为bh

    根节点的黑高称为红黑树的黑高

  3. 结论1: 从根到叶节点的最长路径不大于最短路径的2倍

  4. 结论2: 有n个内部节点的红黑树的高度为$h <= 2log_2{(n + 1)}$

三. B树和B+树

  1. B树, 又称多路平衡查找树, B树中所有节点的孩子个数的最大值称为B树的阶, 通常用m表示
    1. 树中每个节点至多有m棵子树, 即至多含有m - 1个关键字
    2. 若根节点不是终端节点, 则至少有两棵子树

∞. 附录

    n个不同元素进栈, 出栈元素不同排列个数为:

$$
\frac{1}{n+1} C_{2n}^{n}
$$

  1. 树
    1. 二叉排序树(Binary Sort Tree, BST)
    2. 平衡二叉树(Balanced Binary Tree, AVL)
